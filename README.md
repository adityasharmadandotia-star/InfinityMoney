# 📈 InvestInfinity

An AI-powered Stock Price Prediction and Portfolio Optimization platform built using **React, TypeScript, FastAPI, TensorFlow, LSTM, GRU, yfinance, and PyPortfolioOpt**.

The application predicts future stock prices using deep learning models and generates an optimized investment portfolio based on expected return and risk.

> 🚧 **Project Status:** This project is currently under active development. New features and improvements are being added continuously.

---

# ✨ Features

- 📊 Real-time Stock Data (Yahoo Finance)
- 🤖 Stock Price Prediction using LSTM & GRU
- 📈 Historical Price Visualization
- 💼 AI Portfolio Optimization
- ⚖️ Risk vs Return Analysis
- 📉 RMSE, MAE & MAPE Evaluation
- 📊 Interactive Charts
- 🔍 Search Stocks by Symbol
- 🌙 Responsive Modern UI
